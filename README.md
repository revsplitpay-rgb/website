# RevSplitPay Website

Marketing website for RevSplitPay, a Stripe Connect-based commission payout platform for sales teams.

## Development

Install dependencies and start the local development server:

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The production output is generated in `dist`.

## Deployment

Use these settings for Vercel or any static hosting provider that supports Vite:

- Framework: Vite
- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`
